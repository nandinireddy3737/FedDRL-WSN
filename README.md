# FedDRL-WSN: Federated Deep Reinforcement Learning for Wireless Sensor Networks

## Overview

Wireless Sensor Networks (WSNs) consist of sensor nodes that collect and transmit data while operating with limited energy resources. Efficient cluster-head selection and routing are essential for reducing energy consumption, improving network lifetime, and maintaining reliable communication.

**FedDRL-WSN** implements a multi-objective optimization-enabled, drift-adaptive Federated Deep Reinforcement Learning framework for cluster-head selection and routing in Wireless Sensor Networks.

The framework integrates multi-objective optimization, attention-based feature representation, federated learning, adaptive reinforcement learning, and concept-drift detection to support energy-aware network operation.

## Key Features

- **E-MOSSO:** Enhanced Multi-Objective Salp Swarm Optimization for cluster-head selection and reinforcement learning hyperparameter optimization.
- **PMAM:** Parallel Mixed Attention Mechanism for representing important network-state features.
- **A-AC-PPO:** Adaptive Actor-Critic Proximal Policy Optimization for routing and next-hop selection.
- **Federated Deep Reinforcement Learning (FedDRL):** Enables collaborative learning across clients through federated policy aggregation.
- **DRND:** Distributional Random Network Distillation to support exploration.
- **Smooth Policy Clipping:** Supports stable reinforcement learning policy updates.
- **ADWIN:** Adaptive Windowing for detecting changes in network-state distributions and supporting adaptation.
- **Performance Evaluation:** Evaluates network performance using energy, lifetime, and communication-related metrics.

## Proposed Methodology

The framework combines the following components:

1. **Wireless Sensor Network Initialization:** Initializes the network nodes, energy parameters, and base stations.
2. **Network-State Generation:** Generates network-state information for decision-making.
3. **Cluster Formation:** Forms clusters and selects cluster heads using E-MOSSO.
4. **Feature Representation:** Uses PMAM to process relevant network-state features.
5. **Adaptive Routing:** Applies A-AC-PPO to learn routing and next-hop decisions.
6. **Federated Learning:** Aggregates local learning updates to obtain a global policy.
7. **Drift Detection and Adaptation:** Uses ADWIN to detect changes in network conditions and support policy adaptation.
8. **Performance Evaluation:** Calculates and visualizes network performance metrics.

## How to Run

1. Clone or download this repository.
2. Open MATLAB.
3. Set the MATLAB Current Folder to the project directory.
4. Ensure the `SubCode` folder is available on the MATLAB path.
5. Open `Main.m`.
6. Run `Main.m` to execute the simulation.
7. Review the generated performance metrics, tables, and plots.

If MATLAB reports that a function cannot be found, check whether the project directory and `SubCode` folder have been added to the MATLAB path.

## Performance Evaluation

The project evaluates network performance using metrics such as:

- Total energy consumption
- Average residual energy
- Network lifetime
- First Node Dead (FND)
- Half Nodes Dead (HND)
- Last Node Dead (LND)
- Packet Delivery Ratio (PDR)
- Throughput
- Communication-related performance

The reported values should be taken from the simulation outputs generated by the current implementation.

## Research Objective

The objective of this project is to investigate an integrated optimization and federated reinforcement learning framework for energy-aware cluster-head selection and adaptive routing in Wireless Sensor Networks.

The framework combines multi-objective optimization, attention-based state representation, federated policy learning, exploration support, stable policy updates, and drift detection to address changing network conditions.
